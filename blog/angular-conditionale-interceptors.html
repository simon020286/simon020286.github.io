Angular interceptor condizionali

14/02/2025
#angular#interceptor

Spesso mi sono trovato a dover scrivere degli interceptors in Angular, soprattutto per gestire delle chiamate con autenticazione.Il problema che riscontravo ogni volta era di poter aggiungere il token di autenticazione solo nella chiamate che volevo. Purtroppo gli interceptor di angular sono in ascolto su ogni chimata, quindi come fare a gestire solo quelle che mi interessavano?Cercando su internet si trova subito un metodo abbastanza semplice per gestire questa cosa, utilizzare il context delle chiamate dell' HttpClient

/* file auth.interceptor.ts */

export const AUTHENTICATION_ENABLED = new HttpContextToken<boolean>(() => false);

export function authInterceptor(req: HttpRequest<unknown>, next: HttpHandlerFn): Observable<HttpEvent<any>> {
    if (!req.context.get(AUTHENTICATION_ENABLED)) {
        return next(req);
    }

    req = req.clone({
        setHeaders: {
            Authorization: `Bearer prova`
        }
    });
    return next(req);
}

/* file app.component.ts */

import { HttpClient } from '@angular/common/http';
import { Component, inject, OnInit } from '@angular/core';
import { RouterOutlet } from '@angular/router';
import { AUTHENTICATION_ENABLED } from './auth.interceptor';

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [RouterOutlet],
  templateUrl: './app.component.html',
  styleUrl: './app.component.css'
})
export class AppComponent implements OnInit {
  
  title = 'interceptors';
  private httpClient = inject(HttpClient);

  ngOnInit(): void {
    this.httpClient.get('https://jsonplaceholder.typicode.com/posts', {
      context: new HttpContext().set(AUTHENTICATION_ENABLED, true)
    }).subscribe(console.log);
    this.httpClient.get('https://jsonplaceholder.typicode.com/users').subscribe(console.log);
  }
  
}

In questo modo aprendo i DevTools nel tab relativo alle chiamate di rete potrete osservervare come nella prima chiamata verrà aggiunto l'header Authorization mentre nella seconda no.La soluzione potrebbe essere già questa, ma ovviamente a me non piace dover ogni volta creare HttpContext e settare il token, per questo motivo ho pensato a come rendere più semplice questa cosa e soprattutto più intuitiva da utilizzare.Perché non creare un metodo che si occupi di tutto questo e semplicemente passarlo come paramentro alla chiamata http?Per farlo possiamo aggiungere questo codice al file auth.interceptor.ts.

type HttpClientOptionsType = Parameters<HttpClient['get']>[1];

export const withAuthentication = (options?: HttpClientOptionsType): HttpClientOptionsType => {
    const context  = options?.context || new HttpContext();
    context.set(AUTHENTICATION_ENABLED, true);
    return {
        ...options || {},
        ...{ context }
    };
};

In questo modo potremo utilizzare HttpClient in questo modo.

this.httpClient.get('https://jsonplaceholder.typicode.com/posts', withAuthentication());

Ecco fatto, in questo modo mi sembra abbastanza semplice e immediato aggiungere l'autenticazione solo dove serve. Per come è scritto il metodo withAuthentication è possibile passargli come options le stesse che si possono passare ai metodi di httpClient. È anche possibile utilizzare più interceptor condizionali uno dentro l'altro ad esemptio withAuthentication(withLogger()), così da avere la massima flessibilità.Spero di aver dato uno spunto utile.Alla prossima
