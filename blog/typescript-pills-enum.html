Pillole di typescript - Evitare gli enum

13/02/2025
#pills#typescript

TypeScript offre il costrutto enum per definire insiemi di valori nominativi, simili alle costanti. Tuttavia, il loro utilizzo presenta diversi svantaggi che spesso li rendono una scelta subottimale rispetto ad alternative più moderne e flessibili. In questo articolo, esploreremo i principali problemi degli enum e le soluzioni alternative.

Perché non usarli

Gli enum in TypeScript non vengono semplicemente rimossi in fase di compilazione, ma generano codice JavaScript. Ad esempio:

enum Status {
  Pending,
  Approved,
  Rejected,
}

Viene compilato così:

var Status;
(function (Status) {
  Status[(Status["Pending"] = 0)] = "Pending";
  Status[(Status["Approved"] = 1)] = "Approved";
  Status[(Status["Rejected"] = 2)] = "Rejected";
})(Status || (Status = {}));

Questo significa che gli enum generano codice runtime aggiuntivo, aumentando il peso del bundle e introducendo potenziali problemi di performance rispetto a soluzioni più leggere come le union types.
A differenza di altre strutture dati di TypeScript, gli enum non si comportano come oggetti JavaScript standard. Questo può portare a problemi di compatibilità quando si lavora con librerie JavaScript esistenti o quando si effettua la serializzazione/deserializzazione di dati JSON.
Ad esempio:

const status: Status = JSON.parse('{"status": "APPROVED"}');

Questo codice causerà un errore, perché TypeScript non riconosce la stringa come un valore valido dell'enum.
In ultimo poiché gli enum vengono convertiti in oggetti JavaScript, i nomi delle chiavi non possono essere abbreviati dai minificatori, aumentando inutilmente la dimensione del codice finale.

Alternative agli Enum

1. Union Types

Le union types sono un'alternativa più leggera ed efficace:

type Status = "PENDING" | "APPROVED" | "REJECTED";

Questo approccio offre:

  • Zero codice runtime (TypeScript lo rimuove completamente in fase di compilazione).
  • Maggiore compatibilità con JSON e librerie JavaScript.
  • Controllo dei tipi e autocompletamento senza generare overhead.

2. Oggetti Come Enum

Se si desidera mantenere la struttura chiave-valore, è possibile usare oggetti:

const Status = {
  Pending: "PENDING",
  Approved: "APPROVED",
  Rejected: "REJECTED",
} as const;

type Status = (typeof Status)[keyof typeof Status];

Questo metodo mantiene tutti i vantaggi delle union types e offre una rappresentazione più naturale in JavaScript.

Sebbene gli enum possano sembrare utili, i loro svantaggi in termini di output JavaScript, compatibilità e minificazione ne rendono sconsigliato l'uso nella maggior parte dei casi. Le union types e gli oggetti costanti sono soluzioni più efficienti e moderne per gestire insiemi di valori in TypeScript.
